# Reflection

This laboratory activity helped me understand how a cloud-based Linux environment can be accessed and used through KillerCoda. I learned how to create and manage a Linux user account, navigate directories, and gather basic system information such as the operating system, kernel version, CPU, memory, and available disk space.

I also learned the importance of organizing technical files and documenting my work using Markdown. Creating the GitHub repository gave me a place to keep my laboratory activities and evidence organized. Overall, the activity helped me become more familiar with Linux and introduced me to documentation practices that are useful in cloud computing.
