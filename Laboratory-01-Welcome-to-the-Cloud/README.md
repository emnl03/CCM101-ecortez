# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced the basic working environment of a cloud engineer. The activity involved using the KillerCoda Linux Playground, exploring the Ubuntu environment, creating a Linux user account, gathering system information, organizing files and directories, and documenting the work in a GitHub repository.

## Objectives

- Access and use a cloud-based Linux environment through KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed an Ubuntu Linux environment through KillerCoda.
- Created the Linux user account `ecortez`.
- Logged into the newly created user account.
- Checked the current username, working directory, and hostname.
- Identified the Linux distribution and kernel version.
- Gathered CPU, memory, and disk space information.
- Created a Linux workspace containing the `Notes`, `Reports`, and `Screenshots` directories.
- Created and documented Markdown files.
- Created a public GitHub repository for the Cloud Computing portfolio.

## Linux Commands Used

- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the system hostname.
- `adduser` – creates a new user account.
- `usermod` – modifies a user account and adds it to the sudo group.
- `su` – switches to another user account.
- `cat` – displays the contents of a file.
- `uname -r` – displays the Linux kernel version.
- `lscpu` – displays CPU information.
- `free -h` – displays memory information.
- `df -h` – displays disk space information.
- `mkdir` – creates directories.
- `cd` – changes the current directory.
- `ls` – lists files and directories.
- `nano` – opens a text editor for creating and editing files.

## Skills Learned

Through this activity, I learned how to work inside a cloud-based Linux environment, navigate the Linux file system, create and manage user accounts, gather basic system information, organize files and directories, create Markdown documentation, and maintain a GitHub repository for my laboratory work.
