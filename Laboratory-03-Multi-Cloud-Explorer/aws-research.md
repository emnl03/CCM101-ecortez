# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a broad range of services for computing, storage, databases, networking, security, analytics, artificial intelligence, and other technologies. AWS allows organizations to use cloud resources without having to maintain all of the physical infrastructure themselves.

AWS is one of the major public cloud platforms and supports organizations ranging from startups to large enterprises.

## Global Infrastructure

AWS operates a worldwide cloud infrastructure organized into geographic **Regions** and **Availability Zones**. An AWS Region is a geographic area containing multiple isolated Availability Zones. AWS states that its infrastructure currently spans **39 geographic Regions and 123 Availability Zones**.

Availability Zones are physically separated locations within a Region that are designed to provide independent infrastructure and improve application availability and fault tolerance. AWS also provides other infrastructure options, including Local Zones and edge locations, for applications that require lower latency.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS cloud services. It provides a centralized way to work with AWS resources, select Regions, monitor resources and service usage, manage users, and access billing and support information.

The console allows users to access individual AWS service consoles from one web interface.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides resizable computing capacity in the AWS Cloud. Organizations can use EC2 instances to run applications, websites, and other workloads.

### 2. Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve data. It can be used for backups, archives, application data, and other types of files.

### 3. Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows organizations to create a logically isolated virtual network within AWS. It provides control over networking resources such as IP addresses, subnets, routing, and network security.

### 4. AWS IAM

AWS Identity and Access Management (IAM) helps organizations control access to AWS resources. It allows administrators to manage users, permissions, roles, and access policies.

## Three Advantages

### 1. Broad Service Selection

AWS provides a large collection of cloud services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Global Infrastructure

AWS has a large worldwide infrastructure with multiple Regions and Availability Zones. This allows organizations to deploy applications closer to their users and design systems for higher availability.

### 3. Scalability and Flexibility

AWS allows organizations to provision and adjust cloud resources according to their requirements. This makes it possible to scale workloads as demand changes.

## Typical Enterprise Use Cases

AWS can be used by enterprises for a wide range of workloads, including:

* Hosting websites and web applications
* Running enterprise applications
* Storing and backing up organizational data
* Building databases and data-processing systems
* Developing artificial intelligence and machine-learning applications
* Creating scalable and highly available applications
* Supporting disaster recovery and business continuity
