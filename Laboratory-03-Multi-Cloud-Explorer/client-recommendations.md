# Cloud Platform Recommendations

## Client A – Startup Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform is a suitable choice for the startup because it provides scalable cloud infrastructure that can support the company's growth as its mobile application gains users. GCP also provides services that allow the company to start with cloud resources appropriate for its current needs and expand them as demand increases. Its global infrastructure can help the application serve users in different locations. The startup could use **Compute Engine**, **Cloud Storage**, and **Cloud SQL** to build and support its application.

### Services

* Compute Engine
* Cloud Storage
* Cloud SQL

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's ecosystem, making it easier to connect existing systems with cloud services. The university can gradually migrate selected services while continuing to maintain some existing infrastructure. The university could use **Azure Virtual Machines**, **Microsoft Entra ID**, and **Azure Virtual Network**.

### Services

* Azure Virtual Machines
* Microsoft Entra ID
* Azure Virtual Network

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform is a strong choice for the AI research company because the company develops artificial intelligence and machine-learning applications requiring high-performance computing. Google Cloud provides specialized infrastructure and services designed for AI and machine-learning workloads. Its data analytics capabilities can also support research involving large datasets. The company could use **Compute Engine**, **Vertex AI**, and **Google Kubernetes Engine (GKE)**.

### Services

* Compute Engine
* Vertex AI
* Google Kubernetes Engine (GKE)

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is an appropriate choice for the global e-commerce company because it provides extensive global infrastructure and services for building highly available and scalable applications. The company can distribute its workloads across multiple locations and automatically adjust resources as customer traffic changes. AWS also provides services for computing, storage, databases, and application delivery. The company could use **Amazon EC2**, **Amazon S3**, and **Elastic Load Balancing**.

### Services

* Amazon EC2
* Amazon S3
* Elastic Load Balancing
